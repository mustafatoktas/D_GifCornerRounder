<table>
  <tr>

    <th>App Type</th>
    <td>Desktop</td>

<br>

This application rounds the corners of GIF files.

Users can set a corner radius between 1 and 238 for their chosen GIF.

Because the operation runs asynchronously, the interface never locks up, ensuring a smooth, uninterrupted experience.

## Cloning the Project and Inspecting the Code

To clone this repository, open a terminal on a computer with [Git](https://git-scm.com) installed
and run the following command:
